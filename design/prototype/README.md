# راجع — معاينة مختبر الكود

معاينة اليوم الثاني المعتمدة، بدرجات الكحلي والأزرق الداكن وواجهة عربية RTL. هذا المجلد مصدر المعاينة، بينما تطبيق React الأساسي ما زال في `web/`.

## التشغيل

أسهل طريقة: نزّل [`../mockups/raje3-code-lab.html`](../mockups/raje3-code-lab.html) وافتحه في المتصفح؛ الملف مستقل ويضم التنسيق والبيانات والتفاعل.

لتعديل المصدر، افتح `index.html` من هذا المجلد مع إبقاء الملفات الخمسة معًا. يمكن أيضًا تشغيل خادم ملفات محلي من جذر المستودع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/design/prototype/`. لا يوجد تثبيت npm أو build لهذه المعاينة. الخطوط الخارجية اختيارية، وتوجد خطوط بديلة عند انقطاع الاتصال.

## جرّب الرحلة

1. بدّل مثال الدليل بين البريد ورسالة الخطأ وحدود الفحص.
2. اضغط «فحص النطاق»، ثم «بدء المراجعة» لعرض تقرير المثال.
3. صفّ النتائج واختر متطلبًا للاطلاع على دليله وسبب حالته.
4. جرّب «وضع التركيز» على اللابتوب، وتبويبي المتطلبات والدليل على الجوال.
5. افتح مساعدة الاختصارات من أيقونة لوحة المفاتيح. تقليل الحركة في الجهاز يوقف الحركات.

## حدود المعاينة

- جميع النتائج بيانات توضيحية تخص مثال تسجيل الدخول الجاهز.
- اختيار ملفاتك يعرض أسماءها فقط؛ لا تُقرأ محتوياتها ولا تُرفع إلى خادم.
- تغيير الملفات أو المتطلبات لا يولّد مراجعة فعلية أو تقريرًا منسوبًا إلى بياناتك.
- لا يُشغّل الكود أو الاختبارات، ولا تُعدّل الملفات.
- المعاينة غير منشورة على رابط Sites، ولم يُفعّل GitHub Pages بهذا الرفع.

## الملفات

| الملف | الغرض |
|---|---|
| `index.html` | هيكل الوثيقة وتحميل الخطوط والملفات |
| `tokens.css` | قيم الألوان والخطوط والمسافات والحركة |
| `style.css` | المكونات والتخطيط المتجاوب |
| `data.js` | مثال النتائج المسمى بوضوح كبيانات توضيحية |
| `app.js` | تنقل الشاشات والتصفية والأدلة والتفاعلات |
